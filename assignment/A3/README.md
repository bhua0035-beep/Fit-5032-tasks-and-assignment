# EcoYouth Action - A3 Development Milestone 1 (Push 1)

## Stage 1 Features Implemented:
- **BR (D.1) External Authentication**: Firebase Authentication initialized (`src/firebase.js`) supporting Google Sign-In and credentials with reactive auth persistence in `src/store.js`.
- **BR (D.3) Interactive Table Data (Table 1 - Resources)**: Complete interactive table with column-level sorting (asc/desc), global search, individual column filters, and strictly enforced 10 rows per page pagination.
- **BR (C.3) Rating**: Aggregated 5-star rating system with real-time average calculation and vote counts.
- **BR (E.1) Serverless Cloud Functions Scaffold**: `functions/` directory initialized with Firebase Cloud Functions configuration.

## How to Run:
```bash
npm install
npm run dev
```
